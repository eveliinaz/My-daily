# My Daily - Task & Habit Tracker

My Daily is a free and simple task and habit tracker with a dark purple design. No accounts, subscriptions, or payments needed.

## Features
- Add, edit, and delete tasks
- Set due dates and times
- Track daily habits
- View today's and upcoming tasks
- Works offline
- Saves tasks on your device
- Import and export backups
- Reminders while the app is open

## How to use
1. Download and unzip the files.
2. Upload all 8 files to your GitHub repository.
3. Go to **Settings > Pages**.
4. Select **Deploy from a branch**, choose **main** and **/(root)**, then save.
5. Open your GitHub Pages link to use the app.

On iPhone, open the link in Safari and tap **Share > Add to Home Screen**.

## Important
- Reminders only work when the app is open.
- Tasks are stored locally and don't sync between devices.
- Clearing browser data may delete your tasks, so make backups.
- No ads, accounts, or paid features.

Built with HTML, CSS, and JavaScript. Free to use and easy to customize.
Never post private details, passwords or API keys inside the public repository. Your local tasks are not committed to GitHub by this app, but the static source files are public.
